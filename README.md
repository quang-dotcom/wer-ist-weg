# Wer ist weg?

Private Web-App: zeigt, wer dir auf Instagram entfolgt ist und wer nicht zurückfolgt.
Läuft komplett lokal im Browser, ohne Login, Server oder Tracking. Die Daten kommen aus dem Instagram-Datenexport (JSON/HTML/ZIP) oder aus eingefügtem Text.

Auf dem iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
